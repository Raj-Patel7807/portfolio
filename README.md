# Raj Patel — Editorial Developer Portfolio

An editorial developer portfolio built with React 19, TypeScript, and Vite. Crafted with a typography-first aesthetic, fluid responsive layouts, and zero-runtime CSS theming.

🔗 **Live Deployment**: [rajpatel7807.netlify.app](https://rajpatel7807.netlify.app/)

---

## Current Status

- **Phase 0 (Repository Cleanup, Git Audit & Documentation Setup)**: **Completed**
    - Legacy implementations, conflicting dependencies, and duplicate assets cleaned.
    - Media assets and resume consolidated in `public/`.
    - Architecture, design specifications, and implementation prompts established in `docs/`.
- **Sprint 1 (TypeScript & Vite Foundation)**: **Ready to implement**

---

## Tech Stack

- **Framework**: React 19
- **Language**: TypeScript 5 (Strict Mode)
- **Bundler**: Vite 6
- **Styling**: Modern CSS Custom Properties & CSS Modules (Zero-framework, high-performance)
- **Deployment**: Netlify
