# Portfolio Website

Personal portfolio website showcasing my projects, skills, achievements, education, and competitive programming journey.

Built with React, Vite, CSS, JavaScript.

## Run Locally

```bash
git clone https://github.com/your-username/portfolio.git
cd portfolio
npm install
npm run dev
```
